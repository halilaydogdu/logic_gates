# digital logic truth table generator

this is a simple python program for generating truth tables for digital logic gates.

the program supports 2 to 4 inputs and can calculate different logic gates.

## features

* supports 2 to 4 inputs
* automatically creates all input combinations
* calculates truth table results
* user can choose which logic gates to use

## logic gates

* AND
* OR
* NOT
* NAND
* NOR
* XOR
* XNOR

## how to use

run the `logic_gates.py` file.

first, enter the number of inputs.

then choose the logic gates you want to calculate.

the program automatically creates the truth table.
